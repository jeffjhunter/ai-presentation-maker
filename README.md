## The outcome

Build a fact-checked presentation through an interview instead of wrestling a blank slide. This skill covers narrative structure, reusable layouts, speaker notes, and Markdown, PPTX, or PDF exports.

## What you get

A structured deck with a clear through-line, speaker notes, and export-ready files.

## Quick start

1. Install the ClawHub skill: `ai-presentation-maker`
2. Run `/ai-presentation-maker`
3. Share the audience, decision, time limit, evidence, and desired next step. Let the interview surface missing facts before slide production.
4. Review the output before publishing, sending, or changing live systems.

## A useful first prompt

```text
Use /ai-presentation-maker with me. First ask only for the information you need to produce a reliable result. Do not invent missing facts, claims, prices, owners, or deadlines. Show me the draft before anything is published or sent.
```
